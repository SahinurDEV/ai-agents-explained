# Module 07 Assignment: Red-Team Your Agent

*Course module: Security, Evaluation and Production (Udemy Section 8)* · Time: 30-90 min

## Your task
Using `project/step07_guardrails`:
1. Write 5 attack prompts (prompt injection, data exfiltration, tool misuse, jailbreak, over-spending loops).
2. Run them against `GuardedAgent` and record which are blocked.
3. Add one new guardrail (e.g. block emails outside `example.com`) and a pytest test for it.
4. Write an evaluation set of 10 normal questions with expected answers and compute pass rate.

## What to submit
Attack log table + your guardrail code + test + eval pass rate.
